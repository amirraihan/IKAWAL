PCAI plugin for OpenCode.

A starter app, OpenCode skills, and deployment artifacts for your team's next app.

Install the OpenCode plugin

  1. Use Python 3.11+ and OpenCode v2.3.2+.
  2. Extract the ZIP and run Install PCAI Plugin.cmd.
  3. Fully quit and reopen OpenCode PCAI. Type /pcai-help.
  4. Use /pcai-start my-team-app in your workspace and open the new app folder.

Open the 14-slide HTML explanation. Arrow keys navigate, O shows the overview, and N shows speaker notes.

Run the app locally

  1. Extract the whole ZIP and install Python 3.11 or newer if needed.
  2. Connect to the PCAI VPN.
  3. In LiteLLM, create a virtual key without selecting a team (or ensure the key allows DeepSeek).
  4. In the extracted folder, double-click Setup App.cmd. Choose DeepSeek from the numbered model list, then paste your LiteLLM key. Asterisks show the pasted characters were received.
  5. Double-click Run App.cmd, then open http://127.0.0.1:8000.
  6. Ask: Compare the North and South pilots. What needs clarification? Download the answer as Markdown.

Use File Explorer to run the CMD files. The first setup downloads Python packages. Wait for SETUP COMPLETE, then run Run App.cmd. Keep the console open while using the app.

Develop with OpenCode

Open this folder as your project in OpenCode PCAI. Say: Use agentic-app-dev to add my feature, then verify the user flow.

Seven skills include pstack workflows for understanding, designing, reviewing, debugging and verifying changes. If the model is not found, type /pcai-check for LiteLLM troubleshooting. Playwright and Context7 MCP entries are optional and initially disabled.

Prepare for PCAI

Your platform operator runs Configure PCAI.cmd, Build Image.cmd, Prepare PCAI Secrets.cmd, and Prepare PCAI Import.cmd. The last command generates the Helm archive for Import Framework. Use assets/app-icon.png for the required icon.

Read README.md for the file map and docs/deploy.md for deployment. Markdown guides can be opened in OpenCode.

No shared API token is included. Each user enters their own key. Deployment needs the registry, gateway, namespace and Keycloak client values supplied by your platform team.
